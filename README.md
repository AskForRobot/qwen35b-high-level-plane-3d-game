# 3D Plane Shooter Game

A simple 3D airplane shooting game built with Three.js.

## Features

- 3D airplane controls with WASD keys
- Shoot bullets with Spacebar
- Enemy planes to destroy
- Score tracking
- Health system
- Explosion effects

## How to Play

1. Open `index.html` in a web browser
2. Use WASD keys to move your airplane
3. Press Spacebar to shoot
4. Destroy enemy planes to score points
5. Don't let enemy planes pass you!

## Technologies

- Three.js for 3D rendering
- Vanilla JavaScript
- HTML5 Canvas
